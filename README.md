# This repository hosts a production-grade, deterministic C++ firmware framework engineered for Permanent Magnet Synchronous Motors (PMSM) in high-performance electric powertrains. By moving beyond traditional linear modulation, the architecture integrates a non-euclidean toroidal spatial mapping and extended zero-sequence harmonic injection. This successfully optimizes DC-bus voltage utilization and minimizes total harmonic distortion (THD). Designed strictly under functional safety principles (ISO 26262 / MISRA C++ guidelines) with zero dynamic memory allocation, the control loop achieves an ultra-low execution latency averaging 0.0967 microseconds per cycle, proving extreme CPU efficiency for hard real-time automotive and aerospace applications.
